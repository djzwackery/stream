Streamlabs Alert Box code

One widget per type/tier/variant. Paste HTML, CSS, and JS into the matching Streamlabs boxes (its JS box can't run a <script> tag). The JS here is a small loader, so paste it once, future fixes reach this widget automatically, no re-pasting.

Enter the API token once, it's remembered on this browser. Set Duration to match Streamlabs' own "Alert Duration", custom code can't read that setting, so a mismatch cuts the outro short or leaves a gap before Streamlabs clears the widget.

The image slot prefers the viewer's real Twitch avatar, falling back to Streamlabs' {img} if that lookup fails. Check "Prefer Streamlabs' image" when that's the meaningful one instead: Power-Ups send their own icon there, not a viewer photo, so the Twitch avatar would be the wrong pick.

Check "Debug overlay" to bake a small on-screen readout into the widget before copying, useful for troubleshooting without devtools.
